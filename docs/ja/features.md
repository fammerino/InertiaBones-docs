# ツールのシステム機能

## コントローラー生成
適用時、リスト内の各ソースボーンに対して以下を生成します：

    PBCTRL_SourceBone
    └── SourceBone_Sim
        └── SourceBone_Jiggle

- 一貫した命名規則
- 重複させずに複数回実行可能
- スキャンにより既存のコントローラーを検出可能

---

## Session Mode (セッションモード)
- ワーキングメッシュをインスタンス化（メモリ内のみ）
- アセットを作成しない
- 完全に元に戻せる
- 素早い試行錯誤に最適

パラメーターの調整に推奨されます。

---

## Persist Mode (Bake)
- 常にクリーンなバックアップから再構築
- 新しいメッシュアセットを作成
- 既存のメッシュを上書きしない
- タイムスタンプ付きの命名でクリーンアップをサポート
- 安全な遅延クリーンアップ（オプションで設定可能）

---

## バックアップシステム
アバターの下にある非表示のオブジェクトに以下を保存します：
- オリジナルのメッシュ
- オリジナルのボーン
- オリジナルのルートボーン
- SkinnedMeshRendererの相対パス

これにより、予測可能な再構築、破損防止、復元が可能になります。

---

## Rolling Cleanup (ローリングクリーンアップ)
ベイク済みメッシュの保持設定：
- 無効 / 1個保持 / 2個保持 / 5個保持
- 参照されていない古いメッシュのみを自動削除します。
