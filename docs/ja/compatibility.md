# 互換性

!!! warning "警告"
    実行時やアップロード時にメッシュやアーマチュアを操作する一部のツールや最適化ツールと併用すると、問題が発生する場合があります。

メッシュが歪む、または特定の条件下で表示がおかしくなる場合は、以下のテストを行ってください。

### 互換性テスト

1. ギミック等のない、クリーンな状態のアバタープレハブにツールを適用してみる。
2. それで問題なければ、使用しているツールやギミックを一つずつ戻して、どれが原因かを特定する。
3. 原因が特定できた場合は、**Contact**セクションの形式に従って報告していただければ幸いです。

### 特定のツールへの対応

#### Modular Avatar Scale Adjuster
FAQに記載の通り、V1.1.0以降では、これらのコンポーネントを自動的に適切な位置へ移動させるトグルが追加されています。

#### StarMesh
InertiaBonesを適用した後に、StarMesh側の「Original Mesh」参照をInertiaBonesが生成したメッシュに更新することで解決する場合があります。
